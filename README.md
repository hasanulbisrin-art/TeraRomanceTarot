# Tera's Romance Tarot 💗
Android app source project.

Fitur:
- Pink/cute tarot UI
- Opening greeting and IYA button
- Shuffle animation
- 5 face-down cards
- Random result from 5 romance cards
- Romance interpretation
- 24-hour cooldown persisted with SharedPreferences
- Countdown timer

Build:
1. Buka folder ini di Android Studio.
2. Biarkan Gradle sync selesai.
3. Build > Build APK(s).
4. APK debug biasanya berada di app/build/outputs/apk/debug/app-debug.apk.

Catatan: project menggunakan Android Gradle Plugin 8.7.3 dan Kotlin 2.0.21.
